# 🏎️ Escudería Xaverian | Formula SAE

Bienvenido al repositorio oficial de la página web de la **Escudería Xaverian**, el semillero de investigación de **Formula SAE** de la **Pontificia Universidad Javeriana**.

Este es un **proyecto personal** enfocado en modernizar la presencia digital del equipo, proporcionando una plataforma interactiva y profesional para dar a conocer nuestra misión, avances técnicos y el talento de nuestros integrantes.

---

## 📌 Sobre el Proyecto

La **Escudería Xaverian** es un grupo interdisciplinar de estudiantes apasionados por la ingeniería automotriz. Nuestro objetivo principal es diseñar, construir y optimizar un monoplaza de alto rendimiento para competir en **Fórmula SAE Brasil**, conectando la teoría académica con la práctica industrial real.

### 🎯 Objetivos de la Página
- **Visibilidad:** Presentar al equipo y sus patrocinadores ante la comunidad universitaria y la industria.
- **Información Técnica:** Detallar las áreas de trabajo (Chasis, Powertrain, Suspensión, etc.).
- **Talento Humano:** Mostrar el perfil de los estudiantes que hacen posible este sueño.
- **Experiencia de Usuario:** Ofrecer una interfaz moderna, rápida y responsive que refleje la identidad de una escudería de carreras.

---

## 🛠️ Tecnologías Utilizadas

Para este desarrollo se han empleado tecnologías web fundamentales, priorizando el rendimiento y la personalización estética:

- **HTML5:** Estructura semántica y optimizada para SEO.
- **CSS3 (Vanilla):** Diseño personalizado con variables CSS, animaciones fluidas y un sistema de diseño "Dark Racing".
- **JavaScript (Vanilla):** Lógica interactiva para el filtrado de miembros, modales dinámicos y efectos de revelación al hacer scroll.
- **Google Fonts:** Tipografías *Barlow Condensed* y *Montserrat* para un look deportivo y profesional.

---

## ✨ Características Principales

- **Diseño Premium:** Estética oscura con acentos vibrantes (Rojo Racing) y efectos de glassmorphism.
- **Filtrado de Equipo:** Un sistema dinámico para explorar a los miembros según su área técnica.
- **Modales Detallados:** Información expandida de cada integrante, incluyendo carrera, rol y enlaces profesionales.
- **Optimización Mobile:** Totalmente adaptable a cualquier tamaño de pantalla.
- **Sección de Patrocinadores:** Espacio dedicado a las organizaciones que apoyan nuestra investigación.

## 🚀 Instalación y Uso Local

Si deseas ver o modificar este proyecto en tu entorno local, sigue estos pasos:

1. **Clonar el repositorio:**
   ```bash
   git clone https://github.com/tu-usuario/Scuderia-Xaverian.git
   ```
2. **Navegar al directorio:**
   ```bash
   cd Scuderia-Xaverian
   ```
3. **Abrir el archivo principal:**
   Simplemente abre `index.html` en tu navegador preferido o usa una extensión como *Live Server* en VS Code.
